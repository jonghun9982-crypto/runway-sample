# 자금 런웨이 샘플

현금 흐름·런웨이 예측 대시보드 (새로 지어낸 예시 데이터 데모)

| 탭 | 기능 |
|---|---|
| 대시보드 | KPI, 월말 현금잔액 실적+전망 차트, 항목별 지출, 수입 vs 지출, 계좌별 잔액, 납기 알림 |
| 기록 | 일자별·월 합계 기록 추가, 백업·가져오기, 전체 초기화 |

- CSV/JSON 기초 데이터 업로드 후 예측 (4가지 방법, 시나리오 조정 가능)
- 모든 데이터는 이 브라우저(localStorage)에만 저장되며 서버로 보내지 않아요.
- 포트폴리오용 예시 데이터입니다. 실제 금액은 업로드한 파일에서만 계산됩니다.
